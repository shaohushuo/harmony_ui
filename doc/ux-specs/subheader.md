来源：设计规范配图（`tool/fetch_ux_images.sh` 抓取），原文 `doc/reference/design/`。
两张图均出自原文「**穿戴设备 子标题**」段落（对应文中「视觉规则」）：

> · 文字左右居中对齐，底对齐。
> · 文字为15vp。超长文本状态下，先换行（建议最多 3 行），放不下 缩小 3 级；再放不下就截断。

**这两张是手表形态的规格，不能当手机 / 平板的子标题令牌使用。**

## 存疑

- `边距2` / `边距3` 的 `2`、`3` 究竟是边距取值还是标注序号，无法确认。实测图上这两条横向尺寸线长度**完全相同**（各 52px，1109–1160 与 1523–1574），若取值为 2 与 3 应成 2:3，故更像「边距」的第 2、3 条编号注记（与「安全距离 10」并列时，10 才明显是取值）。
- `安全距离 10` 同样没有单位，只能依据同段落正文全部用 vp 推断为 vp。
- `_11` 与 `_12` 右半部分是完全同一张标注示意图，两张图的规格没有差别，不要当成两组不同数值。
- 图上的「子标题」条高度、正文行高在图上都没有标注，无法读出。
