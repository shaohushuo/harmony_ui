## 存疑

- `dialog_22.png` 与 `dialog_23.png` 同属「智能穿戴的弹出框」一段，但内容容器宽度不同（181 / 198）、按钮左右边距不同（40 / 10），推测对应穿戴设备上两种不同的弹框形态，原文未点明，无法确认哪个适用哪种场景。
- `dialog_22.png` 的 `80` 与 `dialog_23.png` 的 `26` 都是「屏幕顶边到内容容器顶边」，数值相差很大且图中未说明是不同屏幕尺寸还是不同结构，存疑。
- `dialog_22.png` 的 `40` 与 `dialog_23.png` 的 `10`：图中竖线一端落在按钮外接方框边缘、另一端落在屏幕边缘，是否含按钮热区无法确认。
- 以上穿戴数值图上均未标注单位（vp），按原样记录为纯数字。
