## 存疑

- `button_26.png` / `button_28.png` 的 `9` 只画出「按钮上边缘 → 文字区域上沿」的竖向括号，原文未解释该值含义（顶部内边距或弧形起弧留白无法区分）。
- `button_26.png` / `button_28.png` 的 `24` 位于弧形两端与文字区域之间，随弧形轮廓变化，是否为固定水平内边距存疑。
- `button_38.png` 的 `16` 是**竖向**标注（单按钮行下沿与面板底部粉色条带之间），与原文「按钮两边距离半模态保留左右各 16vp」的方向不一致；左右各 16vp 在该图未单独标注。
- `button_38.png` / `button_39.png` 在图片索引里的 ctx 只是表格分隔行，设备形态是按原文「手机横屏」小节判定的。
- `button_42.png` 的 `181` 量的是「描述文本」区块宽度，`button_43.png` 的 `181` 量的是胶囊按钮宽度；两者同值是否为「腕表内容区固定宽度」未明说。
- `button_43.png` / `button_44.png` 的 `40` 是按钮高度，但也与 `button_34.png` 中大圆按钮内的图标区域边长同值，勿混用。
- `button_45.png` 的 `40` 横向标注跨度较大，是否即「屏幕左右边距」而非按钮外边距，图上无文字说明。
