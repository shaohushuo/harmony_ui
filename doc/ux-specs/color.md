## 存疑

- 图上反复出现的 `Hex: # 20A7CF` 只是界面示意里的当前色值，不是本章规定的规范色值；本批配图未出现 `#E40078` 这类需要收录的规格色值，故未记入规格表。
- `color_02` 的编号 `1`–`4` 只有引线、没有配套图例文字，1/2/3/4 对应的控件名是按引线落点判断的（关闭 / 网格 / 吸管与色值 / 收藏）。
- `color_10` 的三个标题 `Foldable` / `Tablet - Lands` / `Tablet - Ports` 是英文形态名，图上没写对应中文「折叠屏 / 平板横屏 / 平板竖屏」，中文是按语义对应的。
- 原文「保持宽度 480vp 最大宽度」措辞本身重复，照抄，未做订正。
