## 存疑

- `list_20.png`：图上依次标注 48 / 56 / 64 / 64 / 96，第四行是 `64`；原文正文写「48vp、56vp、64vp、72vp 和 96vp」，图与正文的第四档不一致（72 vs 64），以图为准记录，差异留待核对。
- `list_19.png`：第 3、4 行是嵌套标注（4 / 20 / 40、12 / 24 / 24），刻度线彼此部分重叠；`20` 与 `40` 究竟分别指「图标」与「图标热区」无法从图上唯一确定，暂按尺寸与热区记录。
- `list_19.png`：同一张图里出现 `12`（文本到箭头）与两个 `4`（文本到图标、内容到图标组），三处语义不同但数字都很小，易误读；已按位置分行记录。
- `list_03.png`：`4` 只有数字、没有单位，图上未写 vp/fp。
- `list_08.png` / `list_10.png`：`40` 标在带浅色方块的圆形图标上，方块与圆形的边界只差几像素，`40` 指图标本身还是其热区无法确认。
- `list_40.png` / `list_41.png`：圆形表的 `26`、`20`、`9`、`11`、`57` 都是相对表盘弧形边缘量的，切点位置随行高变化，直接照搬到其它行高会偏差。
