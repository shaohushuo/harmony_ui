## 存疑

- `bottomtab_03/04/05/31.png` 底部左右两角的标注为上下两行的「H」「4」：字母 H 无法判读（疑为原文文字被拆行或非标准缩写），只能确认数字是 4；其语义（左右安全间隔？底部内边距？）图上没有说明，未作推断。
- `bottomtab_05.png` 与 `bottomtab_31.png` 右侧的 `工 4` / `工 2` 小尺寸线，量的是「图标区底边到文字区顶边」这段空隙，但无法区分它表示的是两者间距还是文字区上方的安全距，按位置照记。
- `bottomtab_04.png` 顶部 `工 4` 与正文「运营资源可向上出血 4 vp」可对应；底部那个 `工 4` 的语义图上未标明，只按图照记 4，是否同样为「出血/安全间距」存疑。
- `bottomtab_03.png` 的 `24`、`56`、`2`，`bottomtab_04/05/06/31.png` 的 `48` / `56` / `2` / `4` 在图上都没有写单位，未自行补 vp（正文写的是 56vp / 48vp / 24*24vp）。
- `bottomtab_28.png` 的 `4 ↑ Tabs` / `5 ↑ Tabs` 是页签个数，不是尺寸；已单列标为计数项，不参与几何结论。
- `bottomtab_14.png` 的红色播放键、红色「首页」图标、`bottomtab_09.png` 的浅蓝未选中图标均属界面内容或状态色，未当作玫红标注。
- 本批 22 张图的 ctx 中没有出现「穿戴」「手表」「平板」，故未产出 wearable / tablet 数值；全部按手机形态记录。
